# Icons

Lucide icons (ISC licence), 24px grid, 1.75px stroke, round caps and joins. These copies are inked in `#0f1a16` (`ink`) for documents and design tools — in product UI use the `Icon` component, which inherits `currentColor` and mirrors directional icons in RTL. The full curated set is listed in `ZatcaWeb.ICON_NAMES`.

Core meanings: `layout-dashboard` Dashboard · `receipt` Sales/invoices · `file-text` Documents · `users` Customers · `package` Products · `wallet` Payments · `banknote` Expenses · `landmark` Banking · `chart-column` Reports · `calculator` Accounting · `percent` VAT · `shield-check` E-invoicing/compliance · `qr-code` Invoice QR · `scan-line` Receipt OCR · `building-2` Branches/organizations · `store` Suppliers/retail · `workflow` Automations & approvals · `sparkles` Zatca AI · `languages` Language switch.
