# Logos

Original ZatcaWeb marks, outlined (no font dependency). Not affiliated with, and must never be shown beside, the official ZATCA emblem.

- `zatcaweb-wordmark.svg` — primary lockup for light grounds. Tile `#0e6a50` (logo-tile), Z `#ffffff`, pixel `#c9993a` (accent-500), "Zatca" `#0f1a16` (ink), "Web" `#0e6a50` (brand-600).
- `zatcaweb-wordmark-reversed.svg` — for dark grounds (`bg-canvas`/`bg-surface` dark, `brand-900`). Tile `#2fa57d`, Z `#03160f`, "Zatca" `#e8eeeb`, "Web" `#5fd0a7`.
- `zatcaweb-wordmark-ar.svg` — Arabic lockup (زاتكا ويب), mark on the right. Same inks as the primary lockup.
- `zatcaweb-mark.svg` — the mark alone: favicons, avatars, collapsed sidebar, social profiles.
- `zatcaweb-app-icon.svg` — 512px square app icon on a full Palm ground (the OS applies its own mask).

In product UI, prefer the `Logo` component — it follows the theme.
