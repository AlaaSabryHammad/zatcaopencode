# Badge

A short label for a state or attribute, always with a dot or icon so meaning never rests on colour alone.

**Props:** `tone` — `neutral` · `brand` · `success` · `warning` · `danger` · `info` · `accent`; `icon` or `dot`; `size` — `sm` in dense tables. **Children:** one or two words.

- For invoice, quotation and compliance states use `InvoiceStatus`, `QuoteStatus` and `ComplianceStatus` — not a hand-built Badge.
- `accent` marks AI, new or paid-plan features; never a status.
