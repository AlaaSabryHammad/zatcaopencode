# Icon

A Lucide line icon from the curated ZatcaWeb set, 1.75px stroke, colour from `currentColor`.

**Props:** `name` (see `ZatcaWeb.ICON_NAMES`), `size` (16 dense · 18 default · 20–24 feature), `strokeWidth`, `label` (gives the icon `role=img`; omit for decorative icons), `mirror={false}` to stop RTL mirroring.

- Directional icons mirror in RTL automatically. Never mirror QR, clocks or trend arrows.
- Pair icons with text; icon-only controls use `IconButton` with a `label`.
