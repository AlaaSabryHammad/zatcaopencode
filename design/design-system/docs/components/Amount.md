# Amount

Formats money with two decimals, tabular figures and the SAR / ر.س label — use it for every amount.

**Props:** `value` (number), `size` (`sm` · `md` · `lg` · `kpi` · `hero`), `tone` (`success` · `danger` · `muted`), `currency={false}`, `currencyDisplay='both'`, `decimals`, `compact` (`1.3M`), `showSign`.

- Always LTR, even in Arabic. Negative values use a true minus.
