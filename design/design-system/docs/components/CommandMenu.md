# CommandMenu

The ⌘K / Ctrl K palette to search everything and run actions.

**Props:** `open`, `onClose`, `groups` (`[{heading, items: [{id, label, description, icon, shortcut, badge, keywords, onSelect}]}]`), `placeholder`, `defaultQuery`, `aiHint`, `contained`.

- Group results by category (Actions, Invoices, Customers, Products, Reports, Settings). Show recent items when the query is empty.
