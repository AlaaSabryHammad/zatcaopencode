# EmptyState

Friendly empty screen with brand-shape art, one sentence and a create action.

**Props:** `title`, `description`, `action` (primary), `secondaryAction` (e.g. Import), `art` (`'invoice'` · `'customers'` · `'search'`) or `icon` for compact use, `compact`.

- Title states the fact ("No invoices yet"); description says what to do next.
