# Card

The surface for grouped content: title, description, actions, body and optional footer.

**Props:** `title`, `description`, `actions` (ghost/secondary buttons), `footer`, `padding` (`'sm'` · default · `'none'` for flush tables), `tone` (`'brand'` deep green for one hero card, `'sunken'`), `interactive`, `as`. **Children:** the content.

- One `tone='brand'` card per screen at most.
