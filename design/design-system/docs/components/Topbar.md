# Topbar

App header: breadcrumbs, ⌘K search trigger, quick create, notifications, language, theme, help and user.

**Props:** `breadcrumbs` or `title`, `onSearch` (open `CommandMenu`), `quickCreate` (DropdownMenu items), `notifications` (count), `onNotifications`, `onToggleLang`, `theme` + `onToggleTheme`, `user` (`{name, src}`), `onMenu` (mobile drawer).
